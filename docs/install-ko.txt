탭룸 0.7.20 · macOS 로컬 개발판 (Chrome 확장 0.6.24)

채팅 주소    http://127.0.0.1:18840/

일반 Google Chrome
1. 압축을 풀고 설치 폴더를 보관합니다.
2. chrome://extensions 에서 개발자 모드를 켜고 “압축해제된 확장 프로그램을 로드”로 tabroom 폴더를 선택합니다. 현재 프로필의 기존 탭룸을 업데이트하려면 기존 tabroom 폴더에 이번 파일을 덮어쓴 뒤 탭룸 카드의 새로고침을 누릅니다. 첫 설치를 별도로 체험하려면 새 Chrome 프로필에서 불러옵니다.
3. “일반 Chrome 탭룸 열기.command”를 실행합니다. Python 3가 필요합니다. 이 명령은 이 Mac에 채팅 서버와 Chrome CPU 측정 연결을 준비하고 채팅을 엽니다. 재시동 후에도 이 명령으로 열 수 있습니다.

브라우저 에이전트
Codex CLI에 ChatGPT로 로그인한 상태에서 Node.js 25 이상과 Python 3로 실행합니다. “일반 Chrome 탭룸 열기.command”가 기존 로그인 계정을 이용해 로컬 Codex App Server를 연결합니다. 탭룸 기본 모델은 GPT-6 Luna입니다. Aside 확장이나 브리지를 따로 설치할 필요가 없습니다.
#으로 탭을 골라 본문에 넣습니다. # 뒤에 입력하면 주소 추천과 딥링크가 한 줄에 나타납니다. 좌우 키로 선택하면 아래 미리보기가 바뀝니다. Shift+Enter는 칩을 넣고 선택기를 열어 둡니다. 방문 기록은 첫 홈의 안내나 설정에서 허용할 수 있습니다. 탭 관련 칩과 공백만 있으면 버튼과 Enter는 “탭그룹 열기”, 문구나 스킬 칩이 있으면 “보내기”입니다. Shift+Enter는 줄바꿈입니다. 연결 뒤에는 해당 그룹 안의 탭만 에이전트가 조회하고 제어할 수 있습니다.
왼쪽의 “새 채팅”과 탭룸 로고는 같은 홈을 엽니다. 메시지를 보내거나 탭그룹이 열리면 채팅이 목록에 나타납니다. 메시지 없이 그룹을 연 채팅은 목록에서 다시 열어 기존 그룹에서 작업을 시작할 수 있습니다. 제목 API를 설정한 실행기는 첫 실제 메시지로 GPT-6 Luna에 제목을 요청하고, 도착하면 채팅 목록과 연결된 Chrome 탭그룹의 제목을 함께 갱신합니다. 제목 API에는 OPENAI_API_KEY가 들어 있는 로컬 파일을 TABROOM_TITLE_API_KEY_FILE로 지정할 수 있습니다. 채팅 목록에서 열린 그룹은 Chrome 그룹 색으로, 복원할 수 있는 그룹은 옅은 회색으로 탭 아이콘과 개수를 표시합니다. 아이콘이나 개수에 마우스를 올리면 탭 제목 목록이 열립니다. 연결된 그룹의 웹 탭을 보고 있을 때 Chrome 사이드 패널에서 “연결된 채팅 열기”를 누르면 해당 채팅으로 이동합니다.
홈의 “자주 방문하는 사이트”는 Chrome 프로필의 사이트를 최대 4개 보여줍니다. 사이트를 선택하면 입력창에 탭 하나짜리 칩이 들어갑니다. 이 항목에는 Chrome 확장의 자주 방문하는 사이트 권한을 사용합니다.
미리보기 카드의 ×로 해당 Chrome 탭을 닫을 수 있습니다. 제목 옆의 겹친 탭과 × 모양 아이콘은 그룹을 닫고 같은 채팅에 웹 주소와 순서를 저장합니다. “그룹 다시 열기”로 이어가거나 #으로 그룹에 속하지 않은 탭을 골라 전송하면 새 그룹으로 이어갈 수 있습니다.
반복해서 쓸 구성은 미리보기 제목 옆 북마크 아이콘으로 저장합니다. 열린 그룹이 없을 때 # 선택기에서 상하 키로 “저장된 탭그룹”을 고르거나 새 채팅 첫 화면에서 선택합니다. 첫 화면에서 이름에 마우스를 올리거나 키보드로 포커스하면 입력창 위에 저장 당시 화면과 목록의 삭제 버튼이 보입니다. 그룹 칩을 보낸 채팅에 그룹이 열립니다.
“자주 쓰는 작업”을 고르면 문장과 인라인 탭그룹 칩이 입력창에 들어갑니다. 작업에 넣은 칩에는 이름과 주소 순서가 복사되어 원본 묶음을 삭제한 후에도 사용할 수 있습니다. /를 눌러 “자주 쓰는 작업 만들기”, “스킬 만들기”, 등록한 스킬을 고를 수 있습니다.
탭 카드와 에이전트는 탭룸 자체 ID를 사용합니다. “그룹 다시 열기”로 복원하면 같은 ID를 새 Chrome 탭에 연결합니다. 에이전트도 저장된 그룹을 저장·조회·불러올 수 있습니다.
탭룸은 그룹 안의 브라우저 도구를 제공합니다. 브라우저 전체 이력·북마크·보안 설정·쿠키 조회와 로컬 파일 업로드는 그룹의 권한 범위에 포함되지 않습니다. 탭룸 채팅과 그룹 연결은 이 Mac의 탭룸 앱 데이터에 저장됩니다.
탭룸 전용 App Server는 탭룸의 브라우저 도구와 가이드만 사용하도록 구성합니다. 별도의 ChatGPT 컴퓨터 제어와 개인 Codex에 추가한 MCP 서버는 탭룸 채팅에서 비활성화합니다.
브라우저 도구는 작업 목적을, 스킬 로더는 선택한 스킬 이름을 대화 기록에 표시합니다. 상단의 컨텍스트 수치에 마우스를 올리면 최신 모델 요청의 입력·출력과 탭룸 텍스트 추정 내역을 확인할 수 있습니다.
브라우저 스킬은 채팅에 열린 탭그룹이 없을 때 탭을 열고 바로 그룹으로 연결하는 방법을 안내합니다. Chrome 프로필은 연결된 채팅 기준으로 자동 선택됩니다.

대화형 응답
“수량을 바꾸면 합계가 바뀌는 카드와 검색 가능한 비교표를 보여줘”처럼 요청할 수 있습니다. 에이전트가 필요한 입력, 표, 차트와 버튼을 응답 안에 조합합니다. “입력창에 넣기”를 누르면 선택한 값이 채팅 입력창에 들어가고, 내용 확인 뒤 직접 보냅니다.
다른 에이전트와 화면에서 같은 기능을 쓰려면 tabroom/interactive-ui/GUIDE.md의 적용 방법을 참고합니다.
에이전트는 답변에 탭이나 읽은 페이지를 가리키는 칩을 넣을 수 있습니다. 저장된 출처를 가리키면 제목, 도메인과 답변에 고정한 화면을 볼 수 있습니다. 칩을 누르면 저장된 주소를 엽니다. 원래 탭이 다른 페이지로 이동한 경우 출처를 새 탭에 열고 다음에도 재사용합니다. 닫힌 탭을 복원할 때는 기존 탭룸 ID를 유지합니다.

미리보기
오른쪽에는 현재 채팅과 연결된 Chrome 탭 그룹만 표시합니다. 그룹을 연결하지 않은 채팅에서는 오른쪽 영역이 숨겨집니다. 사이드 패널을 열면 같은 탭 그룹이 그곳으로 옮겨갑니다.
탭 수와 관계없이 목록에서 보이는 카드만 실시간 캡처합니다. 카드가 화면 밖으로 완전히 나가면 약 200ms 뒤에 캡처를 멈춥니다. 다시 보이면 마지막 이미지를 먼저 보여주고 실시간 미리보기를 이어갑니다.
캡처는 기본으로 켜져 있습니다. 스위치를 직접 끄면 같은 Chrome 프로필에서 다시 켤 때까지 꺼진 상태가 유지됩니다. 설정의 해상도에서 가볍게 240px, 기본 320px, 선명하게 480px를 고릅니다. 이 값은 캡처의 가로 최대 크기이며 세로는 탭 화면 비율에 맞춥니다. 오른쪽 미리보기와 사이드 패널이 같은 값을 사용합니다. 각 카드의 FPS는 미리보기 표시 속도이며, 화면이 정지해 있으면 낮아집니다.
설정에서 JPEG 또는 PNG, 탭당 FPS 제한, 전체 탭 합계 제한, 제한 없음을 고를 수 있습니다. 신규 기본값은 PNG와 전체 합계 30fps입니다. 각 화면을 더 부드럽게 보려면 탭당 30fps를 선택하세요.
자동 FPS는 최근 5초 평균 PC 전체 CPU가 60% 미만이면 모든 탭 무제한, 60% 이상이면 전체 합계 30fps, 80% 이상이면 작업 중인 탭만 30fps를 적용합니다. 낮은 부하가 10초씩 유지되면 한 단계씩 복구합니다. 작업 탭만 모드를 직접 고를 수도 있습니다. 쉬는 카드에는 마지막 프레임을 남깁니다.
채팅 위에 겹쳐 뜨는 모니터링에서 PC 전체 CPU, Chrome CPU, 미리보기 합계 FPS와 현재 자동 단계를 확인할 수 있습니다. 기본으로 펼쳐져 있고 필요할 때 접을 수 있습니다. 창이 최소화되거나 미리보기 화면이 숨겨지면 캡처를 멈추고, 보일 때 캡처 설정이 켜져 있으면 재개합니다.
Mac에서는 “일반 Chrome 탭룸 열기.command”가 창 가림 감지도 준비합니다. 다른 앱이 Chrome을 완전히 가리면 마지막 프레임을 남긴 채 캡처를 멈추고, 일부라도 다시 보이면 재개합니다.
Windows용 창 감지 보조 프로그램은 Windows에서 Python 3로 tabroom-launcher/install_windows_visibility.py를 실행해 Chrome에 등록합니다. 창 감지 부분의 설치 파일이며 Windows용 탭룸 전체 실행 환경은 별도입니다.
Chrome 웹 스토어 설치에서는 확장 추가 시 브라우저 제어 권한을 함께 확인합니다. 이 ZIP은 개발자 모드에서 불러오는 개발판이므로 설치 화면이 웹 스토어와 다릅니다. 미리보기를 보는 동안 Chrome에 브라우저 제어 중이라는 안내가 표시될 수 있습니다.
그룹 연결 전에는 호형에서 좌우 키로, 연결 후에는 오른쪽이나 사이드 패널에서 상하 키로 참조할 탭을 고릅니다. 입력한 #을 지우거나 Esc를 누르면 선택기와 탭 강조가 해제됩니다. 선택기에서 Enter를 누르면 본문에 칩을 삽입합니다. 호형에서는 고른 카드가 약 450ms 동안 작아지면서 칩 자리로 들어갑니다. 칩 바로 뒤에서 Backspace를 한 번 누르면 삭제됩니다. 같은 창에 탭이 보이면 Chrome 상단도 임시 강조됩니다.
첫 그룹 연결 때는 입력창의 탭 또는 저장된 그룹 칩이 미리보기 카드로 이어져 나타납니다. 이후 그룹에 새 탭을 넣으면 새 카드가 Chrome 순서에 맞춰 나타납니다. 세로 목록에서 #으로 고를 때는 선택 카드가 왼쪽으로 조금 나오고 다른 카드는 오른쪽으로 물러납니다.

CPU 비교
채팅 왼쪽에서 고정 시간 또는 수동 종료를 고릅니다. 원본 영상을 계속 재생하면서 캡처 OFF로 한 번, ON으로 한 번 측정합니다. 1개 논리 코어를 모두 사용하면 100%로 계산합니다. 측정값에는 같은 Chrome 인스턴스 내 다른 창과 공용 프로세스의 작업도 포함됩니다.

영상 테스트
“탭룸 열기.command”는 Google Chrome for Testing에서 전용 프로필을 열고 테스트 영상을 준비합니다.
일반 Chrome에서 직접 열려면 다음 세 페이지를 채팅과 같은 창의 별도 탭에 엽니다.
http://127.0.0.1:18840/demo/motion.html
http://127.0.0.1:18840/demo/lines.html
http://127.0.0.1:18840/demo/orbit.html
각 페이지가 재생 중인지 확인합니다. 각 영상은 1280×720, 30 FPS의 로컬 MP4입니다.
