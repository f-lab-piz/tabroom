# 탭룸 홍보 영상

Playwright로 녹화한 웹 포털 장면을 Remotion으로 편집한 60초 프로젝트입니다. 1920×1080, 30fps이며 한글 자막이 영상에 포함됩니다.

```sh
npm ci
npm run studio
npm run render
```

`story.mjs`에서 자막과 장면 길이를, `index.jsx`에서 영상 레이아웃을 편집할 수 있습니다. `public/`에 편집용 클립이 들어 있습니다.

촬영에는 별도의 촬영 프로필에서 네이버, 메가박스, CGV 공식 YouTube 채널 등 실제 사이트를 열었습니다. 채팅 답변은 해당 사이트를 바탕으로 준비한 예시입니다. 웹 화면과 그룹 생성, 탭 선택, 실제 탭으로 이동, 출처 팝오버는 앱에서 직접 조작해 녹화했습니다.
