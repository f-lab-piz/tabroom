# 탭룸 구현 상태

## 0.7.20 이후

- 외부 PC는 HTTPS 포털에서 해당 PC의 확장에 연결한다. 채팅, 저장된 탭그룹, 자주 쓰는 작업, 스킬을 공유하고 현재 연결 기기에서 그룹을 복원한다.
- 휴대폰은 포털의 **집 Mac Chrome에 연결**을 통해 집 Mac에서 열린 탭을 본다. 탭 미리보기와 터치용 탭 선택을 제공한다.
- 원격 설정, 배포 파일 생성, Codex와 Chrome의 권한 범위를 [원격 접속 설정](../../../docs/remote.md)에 정리했다.

## 버전별 변경

- 0.7.20은 브라우저 스킬에 자연스러운 탭 지목 문장과 출처·로그인 요청 예시를 추가한다.
- 0.7.19는 주소가 있는 출처 칩에서 저장한 주소를 연다. 원래 탭의 주소가 바뀌었으면 같은 그룹에 출처 탭을 열고 반복 클릭에 재사용한다.
- 0.7.18은 `#검색어`의 입력창 표시, 검색 중 상하 키의 커서 이동 방지, 세 선택기의 높이와 키 안내 통일을 적용한다.
- 0.7.17은 `#` 검색 결과와 미리보기를 통합하고, 조합 중인 한글 검색, 첫 홈의 방문 기록 권한 안내, 출처 탭의 같은 탭룸 ID 복원을 제공한다.
- 0.7.16은 `#` 주소 추천과 딥링크의 실제 웹페이지 미리보기 20개를 추가한다. `Shift+Enter`는 칩을 넣은 뒤 선택기를 유지한다.
- 0.7.15는 답변 출처의 원문 강조와 저장된 발췌문을 제거한다. 칩은 탭 이동, 주소 열기, 정지 화면을 제공한다.
- 0.7.14는 답변에 탭과 URL, 원문 발췌, 완료 시점의 정지 화면을 저장하며 해당 탭 또는 저장한 주소에서 출처를 연다.
- 0.7.13은 에이전트 답변의 탭 참조를 인라인 칩으로 표시하고, 마우스를 올리거나 키보드로 포커스할 때 정지 화면을 보여준다.
- 0.7.12는 탭 칩과 공백만 있는 입력을 그룹 열기로 처리한다. 그룹이 열리면 채팅을 저장하며, 자주 방문하는 사이트도 탭 하나짜리 칩으로 들어간다.
- 0.7.11은 첫 요청을 임시 제목으로 표시하고 GPT-6 Luna가 생성한 제목을 채팅과 연결된 Chrome 그룹에 반영한다.
- 0.7.10은 복원할 수 있는 닫힌 그룹의 아이콘과 탭 수를 옅은 회색으로 표시한다.
- 0.7.9는 열린 그룹을 Chrome의 그룹 색으로 표시하고 탭 제목 팝업을 제공한다. 양쪽 미리보기의 제목 옆에 탭 묶음 저장과 그룹 닫기 아이콘을 둔다.
- 0.7.8은 홈과 새 채팅을 같은 작성 화면으로 통합하고 첫 전송에 채팅을 저장한다. 홈에 자주 방문하는 사이트를, 채팅 목록에 탭그룹 상태를 표시한다.
- 0.7.7은 입력창에서 Chrome 사이드 패널로 이어지는 첫 그룹 모션을 실제 도착 카드의 높이에 맞춘다.
- 0.7.6은 호형 선택기를 대화와 입력창 사이에 배치하고 현재 탭, 저장된 그룹, 빈 목록에서 같은 높이와 왼쪽 항목 위치를 유지한다.
- 0.7.5는 탭룸 ID를 선택기, 채팅, 에이전트, 프레임과 모션의 공통 기준으로 사용한다. 첫 그룹 연결 모션은 전송할 때 입력창의 일반 탭 칩과 저장된 그룹 칩에서 출발한다.
- 0.7.4는 브라우저 스킬에 탭 열기와 그룹 연결을 한 번에 실행하는 예제를 추가한다. 프로필은 자동으로 선택되며, 그룹 생성 직후 같은 작업 안에서도 연결 상태를 표시한다.
- 0.7.3은 OS 창 정보로 완전히 가려진 Chrome 미리보기를 정지하고 일부가 다시 보이면 재개한다. 일반 Chrome에서 Mac 감지 신호를 확인했고 Windows용 보조 프로그램은 실기기 검증이 남아 있다.
- 0.7.2는 저장한 그룹의 목록 삭제, 문장과 독립 탭그룹 칩을 담는 빠른 작업, `/` 스킬 목록과 스킬 등록을 지원한다. 브라우저 스킬은 사용자가 특정 탭을 찾거나 직접 조작할 때만 본문 카드를 사용하도록 안내한다.
- 0.7.1은 새 채팅의 저장된 탭그룹에 마우스를 올리거나 포커스할 때 입력창 위에 저장 당시 화면을 호형으로 보여준다.
- 0.7.0은 브라우저 도구를 `browser_repl`과 `browser_guide`로 노출하고, 두 스킬을 `load_skill`로 제공한다. 대화 본문의 탭 카드도 현재 Chrome 탭의 프레임을 읽는다.
- 0.6.9는 채팅 카드와 브라우저 도구에 복원 후에도 유지되는 탭룸 ID를 제공한다. 기존 호형과 새 채팅 첫 화면에서 저장된 탭그룹을 고르며, 같은 기능을 에이전트 도구에서 지원한다.

- 0.6.8은 현재 Chrome 탭의 연결 채팅으로 이동하고 첫 요청의 제목을 채팅·탭 그룹에 적용한다. 두 미리보기에서 탭 닫기, 채팅별 그룹 보관과 복원, 다른 채팅에서 재사용할 탭 묶음, 닫힌 그룹을 대신할 새 그룹 선정을 지원한다.
- 0.6.7은 에이전트 답변에 연결된 탭의 미리보기 카드를 표시하고 카드 클릭을 해당 Chrome 탭에 연결한다.
- 0.6.6은 목록에 보이는 카드만 실시간 캡처하고, 다시 들어온 카드에 마지막 화면을 먼저 표시한다.
- 0.6.5는 호형 입력 모션, 첫 그룹 연결 모션, 기존 그룹의 새 탭 추가 모션, 세로 선택 강조를 각각 적용한다.
- 0.6.4는 호형 카드가 입력창의 탭 칩으로 이어지는 약 450ms 모션을 제공한다.
- 0.6.3은 미리보기 해상도 240·320·480px를 제공하고 두 탭 선택기의 `#`과 칩 삭제를 고친다.
- 0.6.2는 탭룸 전용 App Server에서 외부 컴퓨터 제어 및 MCP 도구를 끈다.
- 0.6.1은 툴 호출 목적과 컨텍스트 사용량을 표시한다. 초기 지침에서 [브라우저 제어](../../tabroom-launcher/skills/tabroom-browser/SKILL.md)와 [인터랙티브 UI](../../tabroom-launcher/skills/tabroom-interactive-ui/SKILL.md) 스킬을 안내한다.
- 0.6.0은 에이전트 답변에 대화형 화면을 지원한다. [에이전트 가이드](../interactive-ui/GUIDE.md)에 재사용 방법을 정리했다.
- 0.5.6은 브라우저 도구 실행이 끝날 때 백그라운드 미리보기가 멈추는 문제를 수정했다.
- 0.5.8은 PC 전체 CPU와 미리보기 합계 FPS, 자동 단계 표시, 작업 탭만 재생, 창 최소화 시 캡처 정지를 지원한다.

- 0.5.3에서 패널 종료와 호형 선택기의 초기 미리보기를 고쳤다. JPEG·PNG, 탭당 FPS, 전체 합계 FPS, 제한 없음 설정을 추가했다.

- 0.5.2에서 탭별 허용 없이 설치 시 승인한 브라우저 제어 권한으로 전체 탭을 미리본다.
- 0.5.1 로컬 개발판에 왼쪽 채팅 목록과 세션별 탭 미리보기를 반영했다.
