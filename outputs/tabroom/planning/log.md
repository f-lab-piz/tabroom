# 기획 기록

## 2026-11-20

일반 Chrome 신규 설치를 기준으로 권한 허용 없는 배포 요건을 명시했다. 세션 탐색과 탭 그룹 범위 지정은 먼저 구현하고, 공식 Chrome 권한 요구가 있는 기능의 일반 배포는 보류한다.

사용자와 설치 시 한 번 권한 확인을 하는 것으로 기준을 갱신했다. 이후 탭별 승인 없이 브라우저 제어 권한으로 미리보기를 제공한다.

### 저장된 탭그룹과 새 채팅 시작

탭룸 자체 ID로 복원 전후의 탭 참조를 유지한다. 저장된 탭그룹은 열린 그룹이 없는 채팅의 호형 선택기와 새 채팅 첫 화면에서 고른다. 새 채팅 첫 화면은 편집 가능한 작업 문구 세 개를 함께 제공한다. 탭별 정지 이미지 저장과 같은 저장소를 쓰는 에이전트 도구를 포함한다.

## 2026-11-21 · 홈과 채팅 탐색

기본 주소, 탭룸 로고와 새 채팅 버튼은 입력을 준비하는 홈을 연다. 첫 전송이 처리될 때 채팅이 목록에 등록된다. 주소에 저장된 채팅 ID가 있으면 해당 채팅을 연다. 홈에는 Chrome이 집계한 상위 사이트 네 개까지 표시하고, 채팅 목록에는 실제 열린 탭그룹과 보관된 탭그룹을 파비콘과 개수로 표시한다.

### 열린 그룹 표시와 미리보기 버튼

채팅 목록의 파비콘과 개수는 열린 Chrome 그룹의 색으로 강조한다. 마우스를 올리거나 채팅 행에 키보드로 포커스하면 탭 제목 목록을 펼친다. 보관한 그룹은 채팅을 열어 복원한다. 채팅 우측과 Chrome 사이드 패널은 같은 저장·그룹 닫기 아이콘을 쓰며, 그룹 닫기는 현재 채팅에 복원 정보를 기록한다.

닫힌 그룹도 파비콘과 탭 수를 옅게 표시한다. 그룹 색은 열린 그룹에 적용한다.

### 첫 요청으로 채팅 제목 만들기

첫 전송에서 즉시 임시 제목을 표시하고, 첫 요청의 텍스트로 GPT-6 Luna에 제목을 한 번 요청한다. 생성한 제목은 왼쪽 채팅 목록과 연결된 Chrome 그룹에 같이 반영한다. 제목 API 요청이 실패하면 임시 제목을 유지한다.

### 메시지 없이 탭그룹 열기

현재 탭, 저장된 탭그룹과 자주 방문하는 사이트를 모두 작성 화면의 칩으로 넣는다. 칩 사이 공백을 제외하고 탭 관련 칩만 있으면 기본 버튼과 Enter는 탭그룹을 연다. 문구나 스킬 칩이 있으면 메시지를 보낸다. `#` 선택기에 포커스한 Enter는 선택을 확정한다.

홈에서 그룹을 여는 데 성공하면 같은 ID로 채팅을 저장하고 왼쪽에서 다시 열 수 있게 한다. 그룹을 고르기만 한 단계에는 채팅을 저장하지 않는다. 열린 그룹은 첫 메시지에서 재사용하며, 첫 메시지에 제목 생성과 에이전트 실행을 한다.

### 답변의 탭 참조 칩

탭 참조를 문장 안의 작은 칩으로 표시한다. 클릭하면 해당 탭을 열고 키보드 포커스나 마우스 올리기로 한 장의 정지 화면을 본다. 먼저 마지막 프레임을 사용하고 새로 받은 화면은 메모리에만 보관한다. 브라우저 스킬은 사용자가 탭을 찾아야 하거나 직접 조작해야 할 때 칩을 쓰도록 안내한다.

### 답변에 출처와 고정 이미지 남기기

탭 ID와 확인 당시 URL을 기본으로 저장하고, 한 가지만 얻은 경우도 같은 칩으로 표시한다. 브라우저 도구가 근거로 지정한 원문을 읽고 출처 ID를 발급한다. 최종 답변에서는 동일한 문서의 화면만 찍어 고정한다. 클릭 시 당시 실제 문서를 확인하고, 현재 문서가 다르면 저장한 URL을 그룹에 연다. 원문 구간이 있으면 그 위치를 강조한다.

### 답변 출처 칩의 원문 강조 제거

출처에 문단을 지정하는 입력과 발췌문 표시, 클릭 시 원문으로 스크롤하고 강조하는 동작을 제거한다. 저장된 참조에서도 원문 강조 정보를 제거한다. 출처 칩은 같은 문서로 이동하거나 저장한 주소를 열고, 답변에 고정한 화면을 보여준다.

### `#` 주소 추천과 딥링크 검색

`#` 뒤 입력은 하나의 검색 목록에서 두 종류의 결과를 조회한다. 자주 방문한 사이트와 선택 권한으로 조회하는 방문 기록은 주소 추천에 사용하고, 임시 딥링크 API는 등록된 예시 페이지를 검색한다. 결과를 고르면 사이트 칩이 들어가며, 최종 입력을 확정하면 현재 채팅의 그룹에 탭을 연결한다.

<kbd>Shift+Enter</kbd>로 칩을 추가해도 선택기를 열어 둔다. 저장된 탭그룹은 칩 하나로 선택한다. 딥링크에는 영화, 쇼핑, AI·개발 분야의 실제 페이지 20개를 등록하고, 좌우 키로 제목과 설명, 정지 화면을 넘겨 확인한다.

### `#` 검색 결과 통합과 출처 탭 복원

주소 추천과 딥링크를 같은 가로 목록에 표시한다. 같은 주소는 한 항목으로 합치고, 선택한 항목만 미리보기에서 보여준다. 한글 조합 중인 검색어를 반영하고 딥링크 API는 300ms에 한 번씩 최신 표현을 요청한다. 첫 홈에서는 방문 기록 권한이 필요한 사람에게 권한 버튼을 보여준다. 답변의 출처 칩은 닫힌 탭을 기존 탭룸 ID로 복원한다.

### `#` 검색어와 선택기 배치

검색어를 입력한 상태의 상하 키는 편집 커서를 움직이지 않는다. 활성 `#검색어`는 입력창에서 연한 파란 배경으로 구분한다. 현재 탭, 저장된 탭그룹과 검색은 공통 높이와 왼쪽 메뉴, 하단 키 안내를 사용한다.

### 출처 칩과 현재 탭 주소

출처 칩은 저장한 주소를 연다. 원래 탭에서 다른 페이지로 이동했다면 같은 채팅 그룹에 출처용 탭을 하나 열고 반복 클릭에 재사용한다. 현재 주소가 바뀐 원래 탭의 ID와 출처용 탭의 ID를 개별적으로 기록한다.

### 답변에서 탭을 지목하는 문장

사이트 이름이나 화면에서 확인한 구체적 내용 바로 옆에 칩을 둔다. 숫자 탭 ID는 도구와 칩 내부에서 사용한다. 비교, 여러 탭 요약, 페이지 출처와 로그인 요청에 맞는 예시를 브라우저 스킬에 넣는다.
