# 채팅 본문 탭 참조

- 그룹 연결 전에는 현재 창에서 그룹에 속하지 않은 탭을 호형으로 고른다. 연결 후에는 연결된 그룹의 미리보기에서 상하로 고른다. 두 방식 모두 Enter로 커서 위치에 칩을 삽입한다.
- 같은 탭을 본문 여러 곳에 넣을 수 있다. 선택기가 열려 있으면 Enter로 칩을 넣고, 닫혀 있으면 입력창 버튼의 동작을 실행한다. 탭 칩과 공백만 있으면 그룹을 열고, 문구나 스킬이 있으면 전송한다. Shift+Enter로 줄을 바꾼다. 그룹 없는 채팅에서 탭 참조를 담아 전송할 때 선택한 탭으로 그룹을 연결한다. 탭 참조 없는 메시지는 그룹 없이 전송할 수 있다.
- 에이전트는 그룹 연결 전에 현재 창의 미그룹 탭을 조회하거나 새 탭을 열 수 있다. 에이전트가 그룹 생성 도구를 호출하면 Chrome 그룹을 현재 세션에 연결한다. 이후 도구는 연결된 그룹만 보고 제어한다.
- 저장된 사용자 메시지는 문장 안의 참조 위치와 제목을 보존한다. 에이전트에는 순서 있는 참조 ID와 연결된 그룹의 탭 목록을 제공한다.
- 사이드 패널과 포털은 같은 카드, 선택 표시, 스크롤 경계 효과를 사용한다. 두 선택 방식 모두 같은 창의 실제 탭을 ID로 찾아 강조한다. 접힌 그룹이나 다른 창은 카드에서 표시한다. 첫 그룹 연결 시 본문의 칩에서 도착 카드로 이어지는 모션을 준다.
- 답변의 출처 칩은 제목과 도메인, 저장한 정지 화면을 보여준다. 탭룸 ID가 가리키는 탭에 저장한 주소가 열려 있으면 이동한다. 다른 페이지로 이동한 경우에는 현재 페이지를 유지하고 같은 그룹에 출처를 연 뒤 해당 칩에서 그 탭을 재사용한다. 원래 탭이 닫혔고 재사용할 출처 탭도 없으면 기존 탭룸 ID로 복원한다. URL만 저장한 출처도 처음 열린 탭의 ID를 기록한다. 주소 없이 탭 ID만 있는 칩은 그 탭의 현재 페이지로 이동한다.
- 에이전트는 사이트 이름이나 페이지에서 확인한 내용을 문장에 쓰고 바로 옆에 칩을 넣는다. 숫자 탭 ID는 칩과 도구 호출에만 사용한다. 주소가 필요한 출처와 사용자의 조작이 필요한 열린 탭을 구분한다.
