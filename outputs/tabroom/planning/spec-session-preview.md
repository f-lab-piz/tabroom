# 탭룸 배포와 세션별 탭 미리보기

## Problem

새 설치에서도 곧바로 사용할 수 있어야 한다. 기존 포털은 채팅 전환이 상단 메뉴에 있고 우측에는 세션과 무관한 탭까지 보였다. 기존 영상 우선 모드는 실제 탭 화면을 충실하게 재현하지 못했다.

## Target User

일반 Chrome에 탭룸을 처음 설치하는 사용자와 저장한 채팅을 다시 여는 사용자.

## User Value

한눈에 이전 채팅을 찾아 이어갈 수 있고, 현재 채팅이 어떤 Chrome 탭을 참조하는지 바로 알 수 있다.

## Use Cases

- 왼쪽 위 `새 채팅`으로 빈 세션을 만든다. 이 상태의 우측 미리보기는 숨긴다.
- 처음 `#`을 열면 현재 창에서 그룹에 넣을 탭을 고른다. 호형과 세로형 선택을 계속 지원한다.
- 연결한 채팅을 누르면 해당 Chrome 탭 그룹의 현재 탭만 우측에 표시한다. 사이드 패널을 열면 같은 그룹을 표시한다.
- 다시 `#`을 열면 해당 그룹 안에서만 탭을 참조한다. 기존 메시지와 그룹 연결은 다시 열어도 유지한다.

## Corner Cases

채팅을 연달아 바꾸면 이전 요청의 결과를 버린다. 그룹이 닫히면 우측 영역을 숨기고 입력창의 기존 복원 버튼을 제공한다. 탭을 그룹에서 빼거나 추가하면 미리보기 목록이 갱신된다. 기존에 열려 있던 다른 창의 그룹도 같은 그룹 식별자로 조회한다.

## Behavior Spec

왼쪽 목록은 최근 활동순이고, 현재 세션과 그룹 연결 여부를 표시한다. 새로고침 시 마지막 세션을 복원한다. 채팅 전환 즉시 이전 카드와 참조 선택을 비운다. 그룹 연결 전에는 우측 미리보기 영역을 숨긴다. 사용자가 명시적으로 `#`로 최초 그룹 선택을 시작하면 선택 모드에 맞춰 후보를 잠시 표시한다.

미리보기의 목표는 실제 탭의 현재 화면 전체다. 원본 화면 비율을 유지하고 캡처 단계에서 가로 320px로 제한한다. 사이드 패널과 포털은 같은 채팅의 그룹을 사용하며, 양쪽에서 같은 탭을 중복 캡처하지 않는다.

## Cost and Complexity

세션 탐색과 그룹 필터링은 현재 저장소와 Chrome 탭 그룹 API로 구현한다. 화면 캡처에는 설치 때 확인하는 Chrome 디버거 권한을 사용한다.

## Usability

밝은 탭룸 인터페이스에서 왼쪽에 고정 채팅 목록, 중앙에 대화와 입력창, 오른쪽에 연결된 그룹을 배치한다. 창이 좁으면 왼쪽 목록을 버튼으로 열 수 있다.

## Risks and Mitigations

- [Chrome 탭 캡처](https://developer.chrome.com/docs/extensions/reference/api/tabCapture)는 확장 프로그램이 탭 영상·음성 스트림에 접근하기 전에 사용자가 대상 탭에서 확장 기능을 실행하도록 요구한다.
- [Chrome 디버거 권한](https://developer.chrome.com/docs/extensions/reference/permissions-list#debugger)은 탭 화면과 페이지 내용에 광범위하게 접근할 수 있어 Chrome이 [신규 설치 때 권한을 표시](https://developer.chrome.com/docs/extensions/develop/concepts/permission-warnings)한다. 기존 브라우저 제어 기능도 이 권한을 사용한다.
- 포털만 제공하면 화면 접근 권한 없이 세션 탐색을 쓸 수 있다. 실제 탭의 실시간 영상과 제어를 함께 제공하려면 공식 API가 요구하는 사용자 동의가 필요하다.

## Decision

신규 설치 시 Chrome의 권한 확인 한 번을 허용한다. 그 뒤에는 탭마다 권한을 승인하거나 확장 아이콘을 누르는 단계가 없다. 에이전트와 같은 Chrome 디버거 권한을 사용하고, 미리보기는 `Page.startScreencast`로 가로 320px의 전체 탭 화면을 PNG 프레임으로 받아 표시한다.

## MVP Scope

세션 탐색, 새 채팅, 채팅별 그룹 미리보기 목록, 그룹 없는 상태, 사이드 패널 연동, 기존 세션 복원을 구현한다. 사이트별 영상 재생과 이미지 폴백을 제거한다.

## Success Metrics

- 그룹 A에 연결된 채팅에서 그룹 B에 연결된 채팅으로 이동하면 A의 카드가 즉시 사라지고 B의 카드만 표시된다.
- 새 채팅과 미연결 채팅에는 우측 미리보기 영역이 없다.
- 새 프로필에 설치한 뒤 포털에서 캡처를 켜면 백그라운드 탭과 정적인 탭이 개별 권한 동작 없이 표시된다.
- 캡처 정책이 정해지면 같은 영상 탭 세 개에서 20초씩 캡처 꺼짐, 합계 30fps 제한, 제한 없음의 실제 FPS와 Chrome 전체 CPU를 비교한다. CPU 증가폭 30%p 이하가 목표다.

## Open Questions

Chrome 웹 스토어 심사와 배포는 별도 단계다. Chrome 버전과 운영 환경에 따른 CPU 증가폭은 실측이 필요하다.

## Next Actions

새 Chrome 프로필에서 개발판을 검증하고 사용자가 직접 설치할 ZIP을 전달한다.
